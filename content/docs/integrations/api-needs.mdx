## Field assignments

| Field | Bucket | Compliance | Notes |
|---|---|---|---|
| `id` *(requested)* | LMS | — | Join key. Must be immutable. |
| `course_name` | CMS | Review | Public-facing marketing name. Precedent already exists: `internal_name` diverges from `course_name` in 18 of 34 records, meaning the LMS is already carrying a marketing name layer. Names asserting a credential ("BLS Provider") need review before edit. |
| `internal_name` | LMS | — | Operational. Mirrored into Payload read-only as an admin reference so editors can identify the source record. Never rendered publicly. |
| `short_description` | CMS | — | Card and listing copy. Currently unreliable as a description — identical to `course_name` in 5 of 34 records. Treat migration values as a starting point, not content. |
| `full_description` | CMS | Review | See "Description splitting" below. This is the highest-value field for SEO and the one most likely to carry compliance-relevant claims. |
| `category` | Split | — | LMS owns **membership** (which category a course belongs to). Payload owns the **category entity** — display label, ordering, description, SEO metadata for the category page. Requires typed category IDs; see below. |
| `occupations` | CMS | — | Currently ungoverned: 134 distinct values across 34 courses, 9 courses empty, one value carrying a trailing non-breaking space. Seed from LMS values, then curate and govern in Payload. Drives filtering and occupation-targeted landing pages, which are a marketing concern the LMS has no reason to hold. |
| `url` | CMS | — | **Ownership transfer, not documentation of current state.** Today Rails owns course URLs. After replatform the marketing site owns its own URL space, because redirect management and SEO preservation live there. The LMS retains its own internal paths for its own pages. |
| `price` | LMS | Yes | Transactional truth. Never editable. Needs numeric value plus currency code alongside the display string — `"$1,497"` cannot be parsed reliably and schema.org requires a number. |
| `valid_for` | LMS | Yes | Certification validity is a regulatory claim. |
| `ce_credits` | LMS | Yes | Accreditation claim. See the zero-versus-null problem below. |
| `course_length` | LMS | — | Semantics vary by format — 33 records are minute-level durations, one is `"2 days"` (the classroom course). Needs a structured duration where meaningful and an explicit display string where not. |
| `class_format` | LMS | — | Operational truth about delivery. Three values present: Classroom or Online (25), Online Only (8), Classroom Only (1). Drives the render model below. |

### Requested but not in the payload

All LMS-owned when they arrive: audio language, captions language, video count, student manual URL, proof of completion, certification card price, qualifications. Reviews are LMS-owned and were absent from both the payload and the question sheet.

### Payload-only, no LMS counterpart

Owned by Payload outright, no sync: SEO title and meta description, hero and open-graph imagery, selected testimonials, curated related courses, FAQ blocks, trust badges, and any block-composed content on the course page.

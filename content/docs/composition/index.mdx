This section documents what a block is, the three classes blocks fall into, and the rules that decide which class a new block belongs to.

The organizing question is **who supplies the content**. 

## What a block is

A block is a reusable component that defines how content looks on a page and allows editors to change what it says and somtimes modify it's color or what media it displays. On ProTrainings, **pillar pages** are built from blocks that can be chosen and modified by editors.

To keep the admin experience easy and flexible, we're organizing blocks by three different jobs that allow users to:
- Select a branded layout as a page section with editable contents on the page
- Create layouts and editorial grids with simple blocks and rich text elements that are unique to a particular instance
- Define content to be displayed on many pages but managed in one central source of truth: Either the system itself via a query (e.g. display a course, or a group of courses, posts, etc.) or editable content that is modified once and updated in all palcements. 

## Three classes of blocks

| Class | Who supplies content | Who controls arrangement |
| --- | --- | --- |
| **Columns** | Editor composes | Editor, within fixed widths, design sets rules and supplies nestable blocks |
| **Brand Layouts** | Editor fills | Design |
| **Centralized Objects** | The system and/or Editors | Design |


### Columns 

The columns block is a container that works with a set of predefined blocks designed to nest within it. This allows layouts within a page to be composed quickly and on the fly.

### Brand Layouts

Brand layouts are custom layouts that editors can use to quickly add highly designed sections to a page composition.

### Centralized Content

Centralized content blocks use queries to display sets of content from the system or centralizes the content of blocks that may be used on many pages with identical content.

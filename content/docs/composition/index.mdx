Pages on the ProTrainings site are composed from blocks. This section documents what a block is, the three classes blocks fall into, and the rules that decide which class a new block belongs to.

The organizing question is **who supplies the content**. That single axis predicts implementation cost more reliably than visual similarity does, and it is what the three classes below are named for.


## Three classes of blocks

| Class | Who supplies content | Who controls arrangement |
| --- | --- | --- |
| **Columns** | Editor composes | Editor, within fixed widths |
| **Brand Layouts** | Editor fills | Design |
| **Centralized Content** | The system | Design |


### Columns 

The columns block is a container that works with a set of predefined blocks designed to nest within it. This allows layouts within a page to be composed quickly and on the fly.

### Brand Layouts

Brand layouts are custom layouts that editors can use to quickly add highly designed sections to a page composition.

### Centralized Content

Centralized content blocks use queries to display sets of content from the system or centralizes the content of blocks that may be used on many pages with identical content.
